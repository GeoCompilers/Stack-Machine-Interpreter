# Стековая машина на Go

Интерпретатор JSON-инструкций на Go 1.27.1+, без внешних зависимостей.

**Команды:** `READ`, `WRITE`, `CONST`, `LD`, `ST`, `BINOP`, `LABEL`, `JMP`, `JZ`, `JNZ`.

## Устройство и выполнение

Инструкция — одна команда с необязательным операндом. В коде она представлена структурой `instruction`: имя команды, строковый операнд и числовое значение `int32`. Программа хранится в `[]instruction`.

Стек — `[]int32`, его вершина находится в конце среза. Память переменных — `map[string]int32`. Метки хранятся отдельно в `map[string]int32` и связывают имя с индексом инструкции. Указатель инструкций типа `int32` задаёт текущую позицию в программе.

Конструктор разбирает JSON, проверяет команды и строит таблицу меток. `Run` очищает стек и память, затем выполняет инструкции с начала. Обычно указатель движется вперёд, при переходе — к заданной метке. Конец массива завершает выполнение.

`Run` принимает ввод как `[]int32` и два `io.Writer`: для результатов и ошибок. CLI заранее читает и проверяет файлы, передаёт `os.Stdout` и `os.Stderr`. Результаты выводятся через `;`, ошибка возвращается вызывающему коду и завершает CLI с кодом 1.

## Запуск

```text
make build
main.exe -code "code.json" -input "input.txt"
main.exe "code.json" "input.txt"
main.exe --help
```

`code.json` — массив инструкций, `input.txt` — целые числа через запятую или пустой файл. Оба пути обязательны.

Тесты: `make test`.
